## 二、广告法为什么只有 1–67 条（必须写明）

| 尝试 | 结果 |
|---|---|
| samr.gov.cn 2021 修正版原页 | 抓到第 1–67 条，**页面返回 truncated**，第 68 条起丢失 |
| npc.gov.cn | 拿到**完整 75 条**，但那是 **2018 修正版** |
| gov.cn 主席令第八十一号 | 只有公布文，**无修正决定正文** |
| 搜索《八部法律的决定》全文 | 仅找到 `.docx` / `.pdf`，本工具无法解析 |

**两版比对发现的差异**：
- 第二十九条：2018 版含"并办理**广告发布登记**"，2021 版**已删去**
- 第五十七条 / 第五十八条：2018 版有"吊销**广告发布登记证件**"，2021 版已删
- 第六十条：两版**内容不同**（2018 为"未办理发布登记"罚则，2021 为"违反第三十四条"罚则）

→ **编号是否整体前移无法确认**，因此**禁止把 2018 版的 68–75 条接在 2021 版第 67 条之后**。
拼接会造出"看不出痕迹的错版本"，比显式缺失更糟。

**影响评估（为什么可以先这样）**：
本项目判定所引用的条文是**第九条、第十三条、第十六条、第十七条、第十八条、第二十八条**，
全部在 1–67 条范围内，且两版**逐字一致**。缺失的 68–75 条是
"通报机制 / 民事责任 / 任职限制 / 治安处罚 / 审查机关责任 / 公益广告 / 施行日期"，
**不参与任何规则判定**。

**补齐方式（D7 前）**：拿到 2021 修正决定正文后，确认 68–75 是否变动；未变动则补入并更新本台账。

## 三、文件格式约定

每份文件头部固定六行元数据：

```
文件全称：
发布机关：
文号/公告号：
现行版本：
来源链接：
抓取日期：2026-11-01
完整性：完整 / 仅第X–Y条（缺Z）
```

正文后附 `## 核验建议`：列出最容易被引用的 2–3 条，供人工抽查比对。

## 四、入库约定（D2 用）

- 按**条**切 chunk（每条一个 chunk，`law_articles`），metadata 至少含：
  `code`（如"广告法第16条"）、`source`（文件全称）、`doc_type`（law / regulation / guideline / measure）
- **指南类**（03/04/05）`doc_type=guideline`：它们不是法条，但对判定尺度起决定作用，检索时必须能区分
- 清洗规则：**只剥离 HTML 标签（`<div>`/`<table>` 等），不动任何条文文字**
