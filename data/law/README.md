## 二、广告法的版本差异（已确认，2026-11-02）

### 2.1 抓取过程

| 尝试 | 结果 |
|---|---|
| samr.gov.cn 2021 修正版原页 | 抓到第 1–67 条，**页面返回 truncated** |
| npc.gov.cn | 拿到**完整 75 条**，但那是 **2018 修正版** |
| gov.cn 主席令第八十一号 | 只有公布文，**无修正决定正文** |
| 搜索《八部法律的决定》全文 | 仅找到 `.docx` / `.pdf`，本工具无法解析 |
| **作者从官方页面复制第 68–74 条** | ✅ **2026-11-02 补齐，版本谜题解开** |

### 2.2 两版差异（已确认）

| 差异点 | 2018 版 | 2021 版 |
|---|---|---|
| 第二十九条 | 含"并**办理广告发布登记**" | **已删去**（该项行政许可取消） |
| 第五十七条 / 第五十八条 | 含"吊销**广告发布登记证件**" | **已删去** |
| **第六十条** | "未办理广告发布登记"的罚则 | **整条删除** |
| 第六十条及以后 | 自第六十一条起 | **整体前移一位** |
| **总条数** | **75 条** | **74 条** |

**结论：2021 修正删去 2018 版原第六十条，其后各条前移一位，总条数 75 → 74。**
本文第 60–67 条按 2021 版编号；第 68–74 条经作者从官方页面核对后补入，
与原 2018 版第六十九至七十五条一一对应。

> **这就是当初不敢拼接的原因**：若把 2018 版的 68–75 直接接在 2021 版第 67 条之后，
> 会多出一条、编号全错，而且**看不出错在哪**。显式缺失比错误拼接安全得多。

## 三、文件格式约定

每份文件头部固定六行元数据：

```
文件全称：
发布机关：
文号/公告号：
现行版本：
来源链接：
抓取日期：2026-11-01
完整性：完整 / 仅第X–Y条（缺Z）
```

正文后附 `## 核验建议`：列出最容易被引用的 2–3 条，供人工抽查比对。

## 四、入库约定（D2 用）

- 按**条**切 chunk（每条一个 chunk，`law_articles`），metadata 至少含：
  `code`（如"广告法第16条"）、`source`（文件全称）、`doc_type`（law / regulation / guideline / measure）
- **指南类**（03/04/05）`doc_type=guideline`：它们不是法条，但对判定尺度起决定作用，检索时必须能区分
- 清洗规则：**只剥离 HTML 标签（`<div>`/`<table>` 等），不动任何条文文字**
